# Patient forearm and hand asset

`patient_forearm_hand_cc0.obj` is mechanically exported from the Isaac project
USD asset of the same name. The source hand is “Hand realistic” by Dan Ulrich
from Blender Studio Human Base Meshes and is dedicated to the public domain
under CC0 1.0.

The combined asset contains the hand plus a procedural tapered forearm and was
previously reduced to about 82,000 triangles for real-time rendering. In the
MuJoCo scene it is visual geometry. Contact uses aligned tapered forearm,
wrist, palm and finger primitives so the concave hand is not replaced by one
incorrect convex hull.
